# Hospital AI WorkLab · ระดมสมองรายโต๊ะ

Web app สำหรับ workshop ช่วงบ่าย: คลัง prompt 48 สถานการณ์งานโรงพยาบาล ปรับให้ใช้ได้กับโรงพยาบาลทั่วไป (เน้นโรงพยาบาลรัฐ) ผู้เข้าอบรมนั่งเป็นโต๊ะ ลองใช้ prompt แล้วระดมสมองว่าชอบอะไร ไม่ชอบอะไร และจะปรับให้เหมาะกับหน่วยงานของตัวเองอย่างไร


เปิดใช้งาน: https://wirunw.github.io/healthaiworkshop/

## ในหน้ามีอะไร

- **บริบทโรงพยาบาลของโต๊ะ**: กรอกประเภท ขนาด สถานะ HA ระบบที่ใช้ และปัญหาที่สำคัญ ข้อมูลจะเข้าไปใน MASTER CONTEXT ของทุก prompt
- **คลังการ์ด 48 ใบ 10 หมวด**: งานเอกสารและการประชุม ข้อมูลและตัวชี้วัด ยาและพัสดุ อาคารและพลังงาน OPD และเวชกรรมฟื้นฟู Service Plan และระบบนัด กำลังคนและ OPPE เครื่องมือแพทย์ สุขภาวะบุคลากร การเงินการคลังและสิทธิการรักษา แต่ละการ์ดมี Case Context จำลอง, Task Prompt (R–T–F + Guardrails), Follow-up, Human Review Checklist และคำถามชวนคิดสำหรับโต๊ะ
- **กระดานระดมสมองของโต๊ะ**: ชอบ / ไม่ชอบ / ปรับให้เหมาะกับหน่วยงาน ความพร้อม prompt ฉบับโต๊ะ งานแรกที่จะเริ่ม แผน 30 วัน
- **ส่งออก**: ดาวน์โหลดสรุปของโต๊ะเป็น Word และ prompt สำหรับให้ AI ทำสไลด์นำเสนอ 3 นาที

ทุก Case เป็นข้อมูลจำลองเพื่อการฝึกอบรม ข้อมูลที่กรอกเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น
